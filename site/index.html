Options

When a ROM is loaded, its CRC32 is looked up in the patch catalog; matching .bps/.ips patches are offered, newest first, and applied in memory.

Smoother motion on 60 Hz screens: the core shows 4 of every 5 frames. Turn off for native 75.47 Hz timing. Mednafen only: ares and Mesen always run at 75.47 Hz.

Screen

Imitate the real LCD: its duller colour response, and each frame blended with the previous one (flicker becomes steady half-tones; fast motion leaves a slight trail). Remembered per emulator; on by default in ares, off in Mesen. Mesen and ares only.

Enlarge the picture by a whole number only, so every console pixel has the same size (sharper, may leave a border).

Save data

Quick saves stay in this browser, per ROM and per emulator (F5 / F7, slot with 1-3).
